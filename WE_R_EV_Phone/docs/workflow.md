# 르르링 폰 앱 (rrr_phone)

차에서만 하던 충전·주유 전략을 **폰에서 미리** 세우고, 차(Pleos)로 보내서 **주행 데이터로 최종 확정**하는 앱.

```
📅 구글 캘린더에 일정 입력 → 앱에서 [구글 캘린더 연동] (바뀐 일정·장소 감지)
   ↓  (평소 루틴과 다른 일정 감지)
📱 르르르 (Gleo AI 어시스턴트 자리) — 그 지역 충전 인프라 + 유가 + 개인 일정 → 1차 전략
   ↓  [Pleos로 보내기]
🚗 Pleos — 실주행 전비·주행 패턴 반영 → 최종 전략 · 충전 예약 · 경유지 · 내비 위젯
```

## 화면

| 탭 | 내용 |
|---|---|
| 오늘 | 르르르 한마디, 차량 상태, 오늘 일정 + 구간별 전기/발전, 전략 카드(공급 그래프·기름 전략·행동) |
| 캘린더 | 구글 캘린더 연동 카드(연동·동기화·해제), 3주 날짜 띠, 일정 목록(루틴/구글/앱), 구글 일정 탭 → 구글 캘린더에서 수정 → 돌아오면 자동 동기화, `+ 구글 캘린더에 추가`, `빠른 입력`(데모 시트) |
| 르르르 | 대화. 새 일정 → 확인 단계 체크 → “일정이 바뀌었네요!” + 전략 카드. 말로 일정 추가 가능 |
| 차량 | Pleos 차량 상태·주행 데이터, 차에서 하던 원격 기능(충전 예약·목적지·경유지·공조), 최종 전략 |

## 시연 시나리오 (오늘 15:00, 차는 회사 · 배터리 62%)

| 입력 | 르르르 판단 |
|---|---|
| 오늘 저녁 7시 스타필드 하남 쇼핑 2시간 | 하남 완속 30분만 → 집까지 전기, 나머진 심야 집 충전. Pleos 반영 시 40분 |
| 오늘 7시 부모님 댁 저녁 3시간 | 남양주는 급속뿐 → 충전 건너뛰고 긴 구간은 발전 |
| 내일 오후 1시 판교 외근 3시간 | 판교 완속에서 필요한 만큼 |
| 토요일 2시 퇴촌 캠핑 1박 | 충전소 없음·집 못 감 → 고속 구간 발전, 배터리는 V2L·귀가용 |

## 데모 → 최종

| 구간 | 지금 (데모) | 최종 연결 |
|---|---|---|
| 캘린더 | **구글 캘린더 연동 완료** — `GoogleCalendar.kt` (CalendarContract · READ_CALENDAR, 구글 계정 캘린더만). 장소는 데모 DB 매칭 → 실패 시 Geocoder | 장소 → 환경부 충전소 API 로 인프라 조회 |
| 르르르 말·판단 문장 | `LrrrAgent` 템플릿 + 규칙 파서 | Gleo AI 등 LLM (DayStrategy JSON 입력, 행동은 tool call) |
| 하루 전략 계산 | `Schedule.kt` `planDay` (차량 앱 `Planner.kt` 상수·규칙 공유) | 동일 엔진 서버/공용 모듈화 |
| 충전 인프라 · 유가 | `Places.kt` 데모 DB | 환경부 충전소 API · 오피넷 |
| 차량 상태 · 실전비 | 고정값 (62% · 48% · 3.6km/kWh) | Pleos Vehicle SDK / 커넥티드카 API |
| Pleos로 보내기 | 앱 안에서 3.6km/kWh로 재계산 | 차량 앱으로 전략 전송 → 차량 앱 화면·위젯 반영 |
